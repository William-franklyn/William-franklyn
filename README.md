### Selected work

**[Jet Engine Predictive Maintenance](https://github.com/William-franklyn/Jet-Engine-Predictive-Maintenance-ML)** — *Python · PyTorch · Streamlit*

Predicts the remaining useful life of turbofan engines from NASA C-MAPSS sensor data. I ran
five documented rounds of model selection — linear baseline → tuned random forest → rolling
temporal features → LSTM — and kept the negative results in the write-up alongside the wins.

The deployed LSTM lands at **RMSE 16.19 ± 0.35 cycles, R² 0.850**, beating the tuned random
forest by ~2.5 cycles. Every figure is regenerated from an export script, never hand-typed,
and the numbers were re-verified on three separate machines.
